#Pipeline de Testes Automatizados

Projeto desenvolvido para configurar uma pipeline de testes automatizados utilizando Python, Pytest e GitHub Actions.

A aplicação consiste em uma calculadora simples com testes para as operações de:

#Soma
#Subtração
#Multiplicação
#Divisão

Cada operação possui um job independente no GitHub Actions, executado automaticamente a cada push na branch main.
